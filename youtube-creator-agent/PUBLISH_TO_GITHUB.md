# Publish to GitHub

1. On GitHub, create a **public** repository named `youtube-creator-agent` under `Rohit-Kumar-AI`.
2. Do not initialize it with a README, license, or `.gitignore` (these are already included).
3. Extract this ZIP, open a terminal in the extracted `youtube-creator-agent` folder, then run:

```bash
git init
git add .
git commit -m "Build YouTube Creator Agent starter"
git branch -M main
git remote add origin https://github.com/Rohit-Kumar-AI/youtube-creator-agent.git
git push -u origin main
```

4. On the repository page, add these topics: `youtube-agent`, `youtube-agent-skills`, `claude-code`, `codex`, `ai-agents`, `youtube-automation`, `creator-tools`, `python`.
5. Check the README, tests, and skill folders after publishing.

The GitHub URL above is the intended destination; it will work only after you create the repository and push this project.
