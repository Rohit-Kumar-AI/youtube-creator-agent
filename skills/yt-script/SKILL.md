# CreatorPilot: Script Planner

## Workflow
1. Ask for or infer the topic, target viewer, video format, desired length, and the one useful outcome.
2. If important context is missing, state assumptions rather than inventing personal experience, results, statistics, or claims.
3. Draft five genuinely different hooks: problem-first, contrast, specific outcome, question, and story setup. Avoid misleading clickbait.
4. Where available, run `python tools/creatorpilot.py hook "HOOK TEXT"` from the repository root. Explain that the score is a transparent heuristic, not a prediction.
5. Select a hook based on clarity and truthful payoff, not score alone.
6. Create a spoken outline with: opening promise, context, 3–5 beats, example/demo, recap, and a natural call to action.
7. Mark where visuals, examples, or on-screen text could help. Do not fabricate footage or results.
8. End with a short checklist for fact-checking and recording.

## Output
- Audience and promise
- Five hooks with rationale
- Recommended hook and why
- Script/outline with visual cues
- Claims to verify
